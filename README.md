技术栈
- Three.js r169（低多边形 3D 渲染）
- 零构建：原生 ES Modules + <script type="importmap">，无 npm、无打包器
- 纯静态文件部署，服务端仅做静态托管（Caddy）
- 建筑立面为程序化 CanvasTexture（人大红砖 + 窗格），无外部美术资源
选择零构建的原因：目标服务器内存仅 1.9 G，不能跑 npm run build；同时消除构建环节在黑客松现场翻车的风险。

本地运行
ES Modules 不能以 file:// 打开，需要任意静态服务器：
cd ruc-game
python -m http.server 8000
# 打开 http://localhost:8000/
部署
纯静态文件，任意静态服务器 / 对象存储 / Pages 均可托管。生产环境以 Caddy handle_path /rta/* 子路径挂载；换子路径或域名根目录时注意 index.html 中 importmap 与资源均为相对路径（./vendor/...），直接平移即可。建议对 js/css/html 设置 Cache-Control: no-cache（每次校验新鲜度），避免更新后客户端沿用旧缓存。
数据与对接层
src/data/campus.js 是唯一的空间数据源：
- BUILDINGS：建筑清单（位置 / 尺寸 / 高度 / 类型 / 绑定服务）
- ROADS / WATER / PLAZAS：路网、水系、广场
- GATES：校门（门楼朝向与门牌）
- SERVICES：服务定义，bookingUrl 为校方现有预约通道
- CANTEEN_MENU：食堂菜单（当前为 11月22日真实菜单，来源「RUC小通」公众号周菜单）
src/data/cats.js 为校园猫档案（由校园猫志愿团队维护）与彩蛋出现点。
接入真实系统只需改 SERVICES[id].bookingUrl，面板会自动把「通道待接入」占位按钮变成真实跳转链接。
数据来源声明
- 校园布局依据 2026-11-21 实测高德坐标（48 个建筑中心点）线性投影，占地尺寸按高德矢量楼块轮廓估测，非测绘级精度；拿到校方平面图后仅需修改 campus.js。
- 建筑学院/功能介绍来源「RUC小通」公众号官方文章；食堂菜单来源其周菜单推送。
- 校园猫档案由校园猫志愿团队提供；预约类功能当前跳转校方现有通道，获校方支持后可在本平台内直接预约。
- 医疗相关信息以校医院官方发布为准，本项目不构成医疗建议。
